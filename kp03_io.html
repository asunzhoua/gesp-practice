知识点 03：输入输出

掌握 C++ 中 cin/cout 的使用方法和输入输出技巧

cin / cout / endl / 链式输出 9 道练习题
📖 知识要点

1. 基本输出 cout

  • 使用 cout << 内容 输出到标准输出（屏幕）
  • << 称为插入运算符，可以连续使用（链式输出）
  • 输出后需要换行，使用 endl 或 "\n"
cout << "Hello" << " " << "World" << endl;
// 输出: Hello World

2. endl 与 "\n" 的区别

  • endl：输出换行符并刷新缓冲区（flush buffer）
  • "\n"：只输出换行符，不刷新缓冲区
  • 大量输出时使用 "\n" 效率更高，因为避免了频繁刷新缓冲区
  • 在需要确保输出立即显示时（如调试），使用 endl

3. 基本输入 cin

  • 使用 cin >> 变量 从标准输入（键盘）读取数据
  • >> 称为提取运算符，也可以连续使用
  • 读取多个值时以空格、Tab 或换行分隔
int a, b;
cin >> a >> b;  // 一次读入两个整数
// 用户输入: 3 5

4. 链式输出

cout 的返回值是 ostream 对象的引用，因此可以链式调用：

cout << "a + b = " << a + b << endl;

5. 注意事项

⚠ 使用 cin/cout 需要 #include <iostream> 并 using namespace std;

⚠ cin 读取 int 变量时，如果输入的是非数字字符，会导致输入失败

⚠ endl 会刷新缓冲区，频繁使用会影响性能
