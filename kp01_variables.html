知识点 01：变量与数据类型

掌握 C++ 基本数据类型的声明、初始化和使用

int / float / double / char / bool 9 道练习题
📖 知识要点

1. 基本数据类型

  • int 整型，通常 4 字节，范围约 -21 亿 ~ 21 亿
  • float 单精度浮点数，4 字节，约 7 位有效数字
  • double 双精度浮点数，8 字节，约 15 位有效数字
  • char 字符型，1 字节，存储 ASCII 字符
  • bool 布尔型，true 或 false

2. 变量声明与初始化

int age = 15;
double pi = 3.14;
char grade = 'A';
bool isStudent = true;

3. sizeof 运算符

使用 sizeof(类型) 可以查看类型所占字节数。

cout << sizeof(int) << endl;    // 输出 4
cout << sizeof(double) << endl;  // 输出 8
cout << sizeof(char) << endl;   // 输出 1

4. 易错点

⚠ 变量未初始化就使用，值是不确定的（未定义行为）

⚠ int 和 double 混用时注意自动类型转换

⚠ char 用单引号 'A'，string 用双引号 "A"
