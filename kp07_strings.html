知识点 07：字符与字符串

掌握 char 类型与 string 类的基本用法

char / string / 拼接 / 长度 / 输入 8 道练习题
📖 知识要点

1. char 类型

char 用于存储单个字符，使用单引号：

char ch = 'A';     // 字符 A
char digit = '5';  // 字符 5（不是数字 5）
cout << ch;        // 输出 A

2. string 类

string 是 C++ 标准库中的字符串类，使用双引号：

#include <string>
string s = "Hello";    // 字符串
string empty = "";     // 空字符串
cout << s;            // 输出 Hello

3. 字符串拼接

string a = "Hello";
string b = " World";
string c = a + b;      // c = "Hello World"

4. 字符串长度

string s = "Hello";
cout << s.length();   // 输出 5
cout << s.size();     // 也输出 5，和 length() 相同

5. 访问字符

string s = "Hello";
cout << s[0];   // 输出 H
cout << s[4];   // 输出 o

6. 字符串输入

cin >> s 读取一个单词（遇到空格停止），getline(cin, s) 读取整行。

string s;
cin >> s;            // 输入 "Hello World"，s 只得到 "Hello"
getline(cin, s);     // 输入 "Hello World"，s 得到完整一行
