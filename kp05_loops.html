知识点 05：循环语句

掌握 for、while、do-while 循环，以及 break 和 continue 的使用

for / while / do-while 9 道练习题
📖 知识要点

1. for 循环

for (初始化; 条件; 更新) {
    // 循环体
}

已知循环次数时优先使用 for 循环。先执行初始化，每次循环前检查条件，循环体执行后执行更新。

for (int i = 1; i <= 10; i++) {
    cout << i << " ";  // 输出 1 到 10
}

2. while 循环

while (条件) {
    // 循环体
}

先判断条件再执行循环体。如果条件一开始就不满足，循环体一次也不执行。

3. do-while 循环

do {
    // 循环体
} while (条件);  // 注意分号！

do-while 至少执行一次循环体，然后再判断条件。适合需要先执行一次的场景（如输入验证）。

4. break 语句

立即跳出当前最内层的循环，继续执行循环之后的语句。

for (int i = 0; i < 100; i++) {
    if (i == 5) break;  // i=5 时退出循环
    cout << i << " ";   // 输出 0 1 2 3 4
}

5. continue 语句

跳过本次循环的剩余语句，直接进入下一次循环的条件判断。

for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;  // 跳过偶数
    cout << i << " ";           // 输出 1 3 5 7 9
}

6. 常见错误

⚠ 循环变量更新缺失会导致无限循环：如 while (true) 中忘记 break。

⚠ for 循环的三个表达式都可以省略，但分号不能省：for (;;) 是合法的无限循环。

⚠ do-while 末尾的分号不可遗漏。
