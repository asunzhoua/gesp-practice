知识点 08：函数基础

掌握函数的声明、定义、参数传递与返回值

声明 / 定义 / 值传递 / return / void 8 道练习题
📖 知识要点

1. 函数的声明与定义

函数由返回类型、函数名和参数列表组成：

int max(int a, int b);          // 函数声明（原型）
int max(int a, int b) {         // 函数定义
    return a > b ? a : b;
}

2. 函数声明（原型）

函数原型在 main 函数之前声明，告知编译器函数的存在：

int add(int a, int b);  // 声明
int main() {
    cout << add(3, 5);  // 调用
    return 0;
}
int add(int a, int b) {  // 定义
    return a + b;
}

3. 值传递

C++ 默认按值传递参数，函数内修改参数不影响外部变量：

void change(int x) {
    x = 100;  // 只修改了副本
}
int main() {
    int a = 5;
    change(a);
    cout << a;  // 输出 5，a 没有被改变
}

4. return 语句

return 语句结束函数并返回值。遇到 return 函数立即退出。

5. void 函数

返回类型为 void 的函数不返回值，不需要 return 语句（或使用空 return）。

void greet() {
    cout << "Hello!" << endl;
    // 不需要 return
}

6. 参数是局部变量

⚠ 函数的参数和函数内声明的变量都是局部变量，只在函数内部有效。
