知识点 04：条件语句

掌握 if、if-else、if-else if-else 条件判断、嵌套 if 和条件运算符

if / if-else / else if 9 道练习题
📖 知识要点

1. if 语句

if (条件) {
    // 条件为 true 时执行
}

当条件为 true（非零）时执行花括号内的代码，否则跳过。

2. if-else 语句

if (条件) {
    // 条件为 true 时执行
} else {
    // 条件为 false 时执行
}

二选一执行，if 和 else 必然执行其中一个。

3. if-else if-else 多分支

if (条件1) {
    // ...
} else if (条件2) {
    // ...
} else {
    // 以上条件都不满足时执行
}

从上到下依次判断，一旦某个条件满足就执行对应分支，不再判断后续条件。

4. 嵌套 if

if (条件1) {
    if (条件2) {
        // 条件1和条件2都为 true
    } else {
        // 条件1为 true，条件2为 false
    }
}

注意：else 会匹配最近的、未匹配的 if。

5. 条件运算符（三目运算符）

结果 = 条件 ? 值1 : 值2;

条件为 true 时取值1，否则取值2。例如：max = (a > b) ? a : b;

6. 常见错误

⚠ = 是赋值，== 才是比较！

⚠ if 后面不要加分号 if (x > 0); 会导致条件判断无效。

⚠ 花括号不可省略（即使只有一条语句），避免逻辑歧义。
