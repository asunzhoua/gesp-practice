知识点 02：基本运算

掌握 C++ 中算术、比较、逻辑和赋值运算符的使用

+ - * / % == != && || ! 9 道练习题
📖 知识要点

1. 算术运算符

  • + 加法、- 减法、* 乘法、/ 除法、% 取余（模运算）
  • 两个整数相除结果为整数（截断小数部分）：7 / 2 结果是 3 而非 3.5
  • % 取余运算符只能用于整数：10 % 3 结果是 1
  • 想要得到小数除法结果，至少一个操作数需要是浮点数：7.0 / 2 结果是 3.5

2. 比较运算符

  • == 等于、!= 不等于、< 小于、> 大于、<= 小于等于、>= 大于等于
  • 比较运算的结果是 bool 值（true 或 false）
  • 注意区分赋值 = 和比较 ==

3. 逻辑运算符

  • && 逻辑与：两边都为 true 结果才为 true
  • || 逻辑或：只要有一边为 true 结果就为 true
  • ! 逻辑非：取反，!true 为 false，!false 为 true
bool a = true, b = false;
a && b   // false（两边都要 true）
a || b   // true （至少一个 true）
!a       // false（取反）

4. 赋值运算符

  • +=、-=、*=、/= 是复合赋值运算符
  • x += 5 等价于 x = x + 5

5. 运算符优先级（从高到低）

  !  (逻辑非)
  *  /  %  (乘、除、取余)
  +  -  (加、减)
  < > <= >= (比较)
  == !=  (相等)
  &&  (逻辑与)
  ||  (逻辑或)
  =  +=  -=  ... (赋值)

⚠ 优先级影响运算顺序：3 + 4 * 5 先算乘法得 20，再加 3 得 23

⚠ 使用括号可以改变优先级并提高可读性：(3 + 4) * 5 = 35
